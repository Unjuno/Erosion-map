# 1日1文字 侵食マップシステム / Erosion Map

ユーザーが1日1文字を投稿し、受け取り側主体の侵食・相殺を通して日ごとに変わるマップを表示するプロジェクト。

**現在は侵食計算エンジンの試作段階です。** 認証、DB、投稿UI、日次ジョブ、ホスティングは未実装です。

## ローカル検証

Node.js 22以上を使用します。

```bash
npm install
npm test
```

## 仕様上の注意点

- 初期地図は500×500マス。各軸は -250〜249 （両端を含む）。
- **通常の投稿N=1は、影響量N-1=0なので侵食しません。** ゲーム設計上、初期値や蓄積ルールを決定する必要があります。
- 複数勢力の相殺順序、同文字の合算、現住勢力の防御、同期更新は**暫定仕様**です。詳細は [docs/ALGORITHM.md](docs/ALGORITHM.md)。
- ライセンス未設定です。公開リポジトリであっても自由な再利用許諾は意味しません。
- 秘密情報、個人情報、DB認証情報はコミットしないでください。
